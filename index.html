Aula 1

Linguagens de programacao para mobile

Entenda o que sao Kotlin e Swift e para que serve cada uma.

O que e desenvolvimento mobile?

Desenvolvimento mobile e a criacao de aplicativos (apps) que rodam em celulares e tablets. Existem dois grandes sistemas operacionais no mercado:

Android

Sistema do Google. A linguagem oficial e o Kotlin (tambem usa Java).

iOS

Sistema da Apple (iPhone/iPad). A linguagem oficial e o Swift.

Kotlin (Android)

Linguagem moderna, segura e concisa. Exemplo de "Ola, mundo":

fun main() {
    val nome = "turma"
    println("Ola, $nome! Bem-vindos ao mobile.")
}

Swift (iOS)

Linguagem da Apple, tambem moderna e segura. O mesmo exemplo:

import Foundation

let nome = "turma"
print("Ola, \(nome)! Bem-vindos ao mobile.")
Resumo: Kotlin = Android, Swift = iOS. As duas sao parecidas na ideia: declaramos variaveis, chamamos funcoes e mostramos texto na tela.
Aula 2

Estruturas de controle e logica de programacao

Como o programa "toma decisoes" e "repete tarefas".

Variaveis

Sao "caixinhas" que guardam valores. Ex.: idade, nome, preco.

val idade = 18        // Kotlin
let idade = 18        // Swift

Condicionais (if / else)

Servem para o programa decidir o que fazer.

if (idade >= 18) {
    println("Maior de idade")
} else {
    println("Menor de idade")
}

Repeticoes (loops)

Servem para repetir uma acao varias vezes sem reescrever codigo.

for (i in 1..5) {
    println("Contando: $i")
}
Analogia: o if e como um cruzamento: "se o sinal estiver verde, siga". O loop e como escovar os dentes: voce repete o movimento varias vezes.
Aula 3

Boas praticas de codificacao

Como escrever codigo que outras pessoas (e voce no futuro) conseguem entender.

Nomes claros

Prefira quantidadeAlunos em vez de qa ou x.

Comentarios uteis

Explique o "porque", nao o obvio. Comentario bom ajuda, comentario demais atrapalha.

Codigo organizado

Use indentacao e divida o problema em partes pequenas (funcoes).

Nao se repita (DRY)

Se algo se repete, transforme em uma funcao reutilizavel.

Antes x Depois

Evite

fun f(a:Int,b:Int):Int{return a+b}

Prefira

fun somar(numeroA: Int, numeroB: Int): Int {
    return numeroA + numeroB
}
Aula 4

Exercicios de programacao basica

Pratique o que aprendeu. Tente fazer antes de ver a resposta!

Exercicio 1: Crie uma variavel com seu nome e mostre "Ola, [seu nome]" na tela.

val nome = "Maria"
println("Ola, $nome")

Exercicio 2: Verifique se um numero e maior que 10 e mostre uma mensagem.

val numero = 15
if (numero > 10) {
    println("Maior que 10")
} else {
    println("Menor ou igual a 10")
}

Exercicio 3: Mostre os numeros de 1 a 10 usando um loop.

for (i in 1..10) {
    println(i)
}
Dica para a turma: errar faz parte! O importante e testar, ler a mensagem de erro e tentar de novo.
